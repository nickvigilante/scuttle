> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the seven approved round-2 items (feedback items 16, 17, 19, 20, 21, 22, and 23): the reasoning effort follows the web UI and shows in the footer, `/effort` opens a slider, tool summaries fall back to result fields, the live thinking line and running tool marker animate, Markdown links open on click, and `/organization` greys out organizations where the user cannot create chats.

**Architecture:** M1's split holds: `scuttle-core` decides (which effort is sent, which organization new chats use, what a link click's outcome means) with no terminal code, `scuttle-tui` renders and turns clicks into effects, and only `runtime.rs` calls the API or starts a process.

Animation and links both reuse the M1.5 trick that made the tint cheap: the transcript view records row and column metadata when it is built, and the TUI acts on that metadata after rendering (painting spinner frames into marker cells, or hit-testing a click against link columns), so a timer frame still reuses the transcript lines.

## Decisions this plan makes that the spec left open

- **Which effort is sent (item 22).** `App::effort` mirrors the web UI's `pickReasoningEffort` (`site/src/pages/AgentsPage/utils/reasoningEffort.ts:32-50`) as the chat page calls it (`AgentChatPage.tsx:464-471`, `pickReasoningEffort(selectedReasoningEffort || chat?.last_reasoning_effort, efforts, reasoningEffortDefault)`): the effort chosen with `/effort`, else the open chat's `last_reasoning_effort`, used only if the current model offers it; else the model's `model_config.reasoning_effort.default`, if offered; else the model's last (highest) effort.
  It is `None` only when the model offers no efforts, and every create and send carries it, as `submitChatTurn.ts:373-379` does (`reasoning_effort: effectiveReasoningEffort`).
  Like the web UI, a choice the model does not offer skips straight to the default rather than to the chat's last effort.
- **Reversed M1.5 rulings.** The ledger ruling "send reasoning_effort only after /effort picks one" is reversed by item 22, so `effort_label` and the "`None` leaves the server's default" behavior go away, and the tests that encoded them change.
  The ledger ruling "skip the web UI's create-permission filter on organizations" is reversed by item 23.
  The ruling "/organization with a chat open saves the choice and reloads lists on /new" stands, as the round-2 decisions confirm.
- **New chats and the web UI's per-model memory.** The web UI's new-chat form also remembers an effort per model in `localStorage` (`AgentCreateForm.tsx:419-433`, key `agents.reasoning-effort.<model id>`).
  scuttle has no such store and adds no config key for it, so a new chat sends the `/effort` choice, else the model's default, else its highest.
- **Switching models.** A chosen effort the new model does not offer is dropped, and the notice now names the effort that applies instead: "This model does not offer medium reasoning effort; using high."
- **Footer (item 20).** The footer shows the effort in parentheses after the model name, as in "Thinker (high)", and a model without efforts shows its name alone, so M1's footers do not change.
- **Slider (item 21).** `/effort` with no argument opens a slider in the picker's place: a row of the model's effort names, a track under it with a stop centered under each name (`●` at the chosen one, `○` at the others), and the keys in the box's bottom border.
  Left and Right move one stop and stop at the ends, Enter saves through `Msg::EffortChosen` like `/effort <level>`, Esc cancels, and Up and Down do nothing.
  It starts on `App::effort`, so it shows what the next message sends.
  A model with one effort shows one filled stop, and Enter saves that effort.
  The slider stays inside `PickerState` (kind `Picker::Effort`), so the picker's plumbing (Esc, Ctrl+C, overlays blocking clicks) keeps working without a second overlay type.
- **Tool summaries (item 16).** A call's arguments are "not useful" when they have no non-empty string value and every other value is empty (`{}`, `{"parameters": {}}`, `null`, empty arrays).
  Then the summary uses the first non-empty string among the result fields in `RESULT_NAME_FIELDS`, which holds only `workspace_name` for now, because `start_workspace` and `stop_workspace` take only optional `parameters` (`coderd/x/chatd/chattool/startworkspace.go:37-38`) and report the workspace as `workspace_name` (`startworkspace.go:238-261`, and `stopworkspace.go:130-132, 170-172`).
  A result that is a string holding a JSON object is parsed first.
  With neither, the head reads `start_workspace()` instead of `start_workspace({})`.
- **What animates (item 17).** The "∴ Thinking" line of a live reasoning block animates while it is the last block of the live turn and the activity is `Thinking`.
  A tool call's marker animates while the call has no finished result and the agent is working (`App::activity` is `Some`).
  That includes a durable call whose result is still streaming live, because Coder persists the call's message before the result arrives (`live_result_for_a_durable_call_is_shown` in `transcript_view.rs`), so "live" here means "in progress", not "in the live buffer".
  Finished blocks, expanded reasoning (which shows its text, not a marker), and everything after the agent stops keep their static glyphs.
- **How the markers animate without rebuilding (item 17).** The view records the rows whose first cell is an animated marker (`View::spinners`), and `Tui::draw_at` overwrites those cells with the activity spinner's current frame after rendering the lines, the way it paints the user tint.
  A timer frame therefore still reuses `View::lines`, `a_spinner_tick_reuses_the_transcript_lines` keeps passing, and the per-frame cost is one cell write per visible marker, independent of the transcript's length.
  The alternatives were worse: rebuilding on every tick undoes Task 4 of M1.5, and rebuilding only the live group would need every later row offset recomputed.
  `View::lines` keeps the static glyph, so a drag selection copies "◌" or "∴" rather than a spinner frame.
- **Links (item 19).** Links render as underlined text with the text's own color; inline code inside a link is underlined too.
  `markdown::render` records each link's display columns on its rendered line (after any quote marker), a link split by a hard break gets one entry per line, and the transcript view maps each entry onto the soft-wrapped rows it covers, so a link that wraps is clickable on every row.
  Only Markdown links become links: bare URLs stay text, since CommonMark does not link them, and text inside a code block is never a link, because pulldown-cmark reports code block contents as plain text.
- **Link clicks.** A click (a press and release on the same cell, the M1.5 rule) on link text sends `Effect::OpenLink(url)`; a click anywhere else keeps its M1.5 meaning, and a drag over a link selects and copies its text without opening it.
  Clicking link-looking text inside a code block therefore opens nothing and still copies the block, as every click on a code block has since M1.
  A click during streaming resolves against the view pinned at the press, so it opens the link that was under the pointer.
- **Opening links.** The runtime opens only `http` and `https` URLs, parsed with the `url` crate and passed on in normalized form; anything else (`file:`, `javascript:`, a relative path, or text starting with `-` that `open` would read as an option) comes back as a failure, and the UI copies it instead.
  As with `/web`, a link that opened no browser (over SSH, under tests, or rejected) is copied, with the notice "Copied the link: <url>".
- **Organizations (item 23).** The web UI's `permittedOrganizations` (`site/src/api/queries/organizations.ts:308-326`) runs one `POST /api/v2/authcheck` with a check per organization, `{action: "create", object: {resource_type: "chat", owner_id: "me", organization_id: <id>}}`, as `AgentCreateForm.tsx:236-243` calls it; the server resolves `owner_id: "me"` to the caller (`coderd/authorize.go:256-258`).
  The pinned SDK exposes that endpoint as `check_authorization` (`crates/coder-api-gen/src/generated.rs:16468`), so scuttle asks the same question and gets the same answer.
  The difference is the organization list: the web UI checks `GET /organizations`, and scuttle checks the memberships it already loads from `GET /users/me/organizations`.
- **When the check runs.** `Runtime::organizations` runs it at startup, and only when the user has two or more organizations, since with one there is nothing to choose between.
  A failed check marks every organization allowed, so a network blip hides nothing and a create in a disallowed organization still fails with the server's message, as in M1.5.
- **What a denied organization does.** It stays in `/organization`, dimmed and marked "(no permission to create chats)", which is the only reason the server gives, since the check answers yes or no.
  Choosing it, from the picker or by name, is refused with "You do not have permission to create chats in <org>." and nothing is saved.
  The automatic pick skips it too, matching the web UI, which drops a stored choice that is no longer permitted (`AgentCreateForm.tsx:257-265`); with no organization allowed, the pick falls back to the M1.5 order and the server explains on create.
- **Task split.** The effort sync and its footer display are one task, because the footer is how the user sees which effort is sent.
  The slider is its own task, since its layout can be rejected while the sync is approved.
  Tool summaries come before animation because both edit the tool arm of `transcript_view.rs`, and links come after animation because both add a `View` field and draw-time metadata.

    /// The effort sent with the next message, picked the way the web UI picks it
    /// (`pickReasoningEffort` in `site/src/pages/AgentsPage/utils/reasoningEffort.ts:32-50`,
    /// called from `AgentChatPage.tsx:464-471`): the one chosen with `/effort`, else the open
    /// chat's last one, if the current model offers it; else the model's default, if offered;
    /// else the highest. `None` only when the model offers no efforts.
    pub fn effort(&self) -> Option<String> {
        let efforts = self.efforts();
        let offered = |e: &String| efforts.contains(e);
        let wanted = self
            .selected_effort
            .clone()
            .or_else(|| self.chat.as_ref().and_then(|c| c.last_reasoning_effort.clone()));
        wanted
            .filter(offered)
            .or_else(|| {
                self.current_model()
                    .and_then(|m| m.model_config.as_ref())
                    .and_then(|c| c.reasoning_effort.as_ref())
                    .and_then(|r| r.default.clone())
                    .filter(offered)
            })
            .or_else(|| efforts.last().cloned())
    }

/// The slider's two rows: the effort names, and under them a track with a stop centered under
/// each name, filled at `selected`.
pub fn slider_rows(levels: &[&str], selected: usize, theme: &Theme) -> Vec<Line<'static>> {
    const GAP: usize = 3;
    let mut names = Vec::new();
    let mut track = Vec::new();
    for (i, level) in levels.iter().enumerate() {
        if i > 0 {
            names.push(Span::raw(" ".repeat(GAP)));
            track.push(Span::styled("─".repeat(GAP), theme.dim));
        }
        let width = level.width().max(1);
        let left = (width - 1) / 2;
        let (name_style, stop) = if i == selected {
            (theme.accent, Span::styled("●", theme.accent))
        } else {
            (theme.dim, Span::styled("○", theme.dim))
        };
        names.push(Span::styled((*level).to_owned(), name_style));
        track.push(Span::styled("─".repeat(left), theme.dim));
        track.push(stop);
        track.push(Span::styled("─".repeat(width - 1 - left), theme.dim));
    }
    vec![Line::from(names), Line::from(track)]
}

/// The call's arguments on one line: the first non-empty string among them, else all of them
/// as JSON. `None` when they say nothing, such as `{}` or only empty values, so the summary can
/// fall back to the result.
fn args_summary(args: &serde_json::Value) -> Option<String> {
    match args {
        serde_json::Value::Object(map) => map
            .values()
            .filter_map(|v| v.as_str())
            .find(|s| !s.is_empty())
            .map(str::to_owned)
            .or_else(|| {
                map.values()
                    .any(|v| !is_empty_value(v))
                    .then(|| args.to_string())
            }),
        serde_json::Value::Null => None,
        other => Some(other.to_string()),
    }
}

/// Whether `v` holds nothing worth showing: null, an empty string or array, or an object of
/// such values.
fn is_empty_value(v: &serde_json::Value) -> bool {
    match v {
        serde_json::Value::Null => true,
        serde_json::Value::String(s) => s.is_empty(),
        serde_json::Value::Array(a) => a.is_empty(),
        serde_json::Value::Object(m) => m.values().all(is_empty_value),
        _ => false,
    }
}

/// Result fields that name what a tool acted on, for a call whose arguments say nothing.
/// `start_workspace` and `stop_workspace` take only optional `parameters` and report the
/// workspace as `workspace_name` (`coderd/x/chatd/chattool/startworkspace.go:37-38, 238-261`).

/// The first non-empty `RESULT_NAME_FIELDS` value of a result object, parsing a result that
/// arrived as a JSON string first.
fn result_summary(result: Option<&serde_json::Value>) -> Option<String> {
    let parsed;
    let value = match result? {
        serde_json::Value::String(s) => {
            parsed = serde_json::from_str::<serde_json::Value>(s).ok()?;
            &parsed
        }
        other => other,
    };
    let map = value.as_object()?;
    RESULT_NAME_FIELDS
        .iter()
        .find_map(|k| map.get(*k)?.as_str().filter(|s| !s.trim().is_empty()))
        .map(str::to_owned)
}

        // A link still open at a line break goes on from the start of the next line.
        if let Some((url, start)) = self.link.as_mut() {
            if self.current.len() > *start {
                self.line_links
                    .push((*start, self.current.len(), url.clone()));
            }

            self.line_links.clear();
            return;
        }
        let mut spans = Vec::new();
        if self.quote_depth > 0 {

        let line = self.out.lines.len();

/// `rows`, the rows `wrap_line` made of that line, as (row index, columns in that row).
fn link_rows(rows: &[Line<'static>], cols: &Range<usize>) -> Vec<(usize, Range<u16>)> {
    let mut parts = Vec::new();
    let mut at = 0;
    for (i, row) in rows.iter().enumerate() {
        let width: usize = row.spans.iter().map(|s| cells_width(&s.content)).sum();
        let (from, to) = (cols.start.max(at), cols.end.min(at + width));
        if from < to {
            parts.push((i, (from - at) as u16..(to - at) as u16));
        }
        at += width;
    }
    parts
}
