# M2.5: Polish Round 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the twenty M2.5 items of the round-3 feedback (24, 25, 26, 28, 29, 30, 32, 33, 34, 35, 36, 37, 38, 40, 41, 42, 43, 44, 45, and 46): a composer with one rule, real Markdown tables, link hover, footer fields labeled with their commands in the Coder accent, the attached workspace in the footer, the chat title in the terminal tab, a pin marker, summaries, and a visible search row in `/chats`, server search operators documented in `/help`, a bundled Coder wordmark with a trademark credit, web-UI labels for subagent tools, several spinner styles, an interim `/settings`, a copy confirmation above the composer, a five-row slash menu, a hint above the composer that names the key that sends a queued message now, a warning when a chat's model is no longer available with a model pick that keeps the draft, and a key that copies the draft.

**Architecture:** M2's split holds: `scuttle-core` decides (config keys, the `/settings` command and its effect, the search `q`, the workspace name) with no terminal code, `scuttle-tui` renders, and only `runtime.rs` or the main loop's terminal handoff starts a process.
Everything that changes on screen without new data is painted at draw time over reused lines, the way M1.6 paints spinners and the tint: link hover, the turn's spinner frames, and the copy confirmation never bump `view_revision`, so timer and mouse-motion frames keep reusing `View::lines`.
Tables are laid out to the pane width inside `markdown::render`, so a resize rebuilds them through the existing width check in `Tui::draw_at`, and `/settings` reuses the `$EDITOR` handoff with the input thread paused, as Ctrl+G does.

## Global Constraints

- scuttle work happens on branch `m2-polish`, created from `m2` at `3f1024c`.
- Never push, never commit on `main`, never add a remote, and stage only the files a task names; never `git add -A`, because the worktree holds uncommitted documents that are not part of any task.

## Decisions this plan makes that the spec left open

- **Footer fields (items 28, 29).** The fields a command changes are `/model: <name>`, `/effort: <level>` (only when the model offers efforts), `/workspace: <name>`, `/organization: <name>` (only with two or more organizations, as today), and `/plan-mode: on` (only while it is on, as "plan mode" showed only then).
  The context usage and the connection status stay plain, since no command changes them.
  The model and effort become two fields, so "Thinker (high)" now reads `/model: Thinker · /effort: high`.
  `/workspace` shows only while a workspace is attached and the workspace list names it; there is no `/workspace: none`.
  When the line is too long, the workspace goes first, then the organization, then the line is cut as today.
- **Brand accent.** `Theme::brand` is sky-500 `#0ea5e9` on dark terminals and sky-600 `#0284c7` on light ones in 24-bit color (`COLORTERM` of `truecolor` or `24bit`), else indexed 38 (`#00afd7`) or 32 (`#0087d7`), the nearest of the 256 colors, and plain under a non-empty `NO_COLOR`.
  Only the footer's commands and the link hover use it; the rest of the palette is unchanged.
- **Composer (item 24).** `Composer::height` counts one rule row instead of two, so an empty composer is two rows and the minimum the layout gives it is 2.
  The one-line editor box is three rows, so it now draws bottom-aligned on the composer and covers the row above it.
- **Slash menu (item 42).** Up and Down move a highlight through the matches while the menu shows, except while Up and Down are already walking the sent-message history, so recalling a sent `/model` never traps the history walk.
  Tab completes the highlighted entry, Enter still sends the typed text, and any change to the typed text puts the highlight back on the first match.
  The box shows at most five rows, scrolled so the highlight stays in view, and its bottom border says `↓ N more` while matches below are hidden.
- **Copy confirmation (item 41).** Every successful copy from the transcript (a drag, a code-block click, `/copy`) shows "Copied N characters" on the hint row above the composer for two seconds after it is first drawn, or until the next key.
  A clipboard warning, such as tmux dropping OSC 52, still goes to the footer, and a failure stays a footer error.
  URL copies (`/web`, links, `/workspace`) keep their footer notices, since those name what was copied.
- **Queued hint (item 44).** While messages wait, the hint row says `<key> sends the next queued message now` in dim, where the key is the one `is_send_key` accepts on an empty composer: `↵` in Enter mode, and in modifier mode `⌘↵` on macOS or `Ctrl+↵` elsewhere, or `⌥↵` or `Alt+↵` without keyboard enhancement, since Ctrl+Enter and Cmd+Enter then arrive as a plain Enter and Alt+Enter is the fallback.
  The row shows the copy confirmation first, then the hidden-questions hint, then the plan-ready hint, then the queued hint; the question menu and a waiting attachment hide it, because they take the send key first.
  The macOS choice is a `mac` parameter of `composer::send_now_label`, read from `cfg!(target_os = "macos")` only in `Tui::send_now_key`, and `/help`'s "Send now" entry names the same key.
- **Terminal title (item 30).** The title is `scuttle · <chat title>`, with whitespace runs collapsed to one space, control characters dropped, and the chat title cut at 100 characters; a blank chat, a loading one, or an untitled one shows `scuttle`.
  The title stack is pushed when the terminal is entered and popped when scuttle exits or panics; a pager or editor handoff leaves the title alone.
- **Spinners (item 38).** The styles are `braille` (today's), `line`, `arc`, `bounce`, and `bar`, each one cell wide, because the transcript and table spinners are painted into a single cell; the feedback's "bouncing bar" becomes `bar`, a block that grows and shrinks.
  A turn starts when `App::activity` goes from `None` to `Some`, and that is when `"random"` draws a new style.
  The chosen style drives every spinner on screen: the activity row, the transcript markers, uploading chips, and `/chats`.
- **`/chats` (items 32, 33, 34).** The pin marker and one space go before a pinned chat's title; an empty `chats.pin_icon` shows nothing.
  The summary is the last column, dim, shown only when the overlay is at least 100 columns wide, with its whitespace runs collapsed.
  The filter line reads `Search: ` and shows "Type to filter, or search all chats" while it is empty.
  For the "Search all chats" row, each term whose key the server accepts (`archived`, `has_unread`, `status`, `pr_status`, `diff_url`, `title`, `pr_title`, `repo`, `source`, `pr`, `search`, any case) goes into `q` as typed, quotes kept, and the remaining words become one `search:"…"` term, since the server refuses a bare word; the server's own refusals, such as `search` combined with `title`, show as its message.
- **Tables (item 25).** A table is a box: a top rule, the header row, a `├┼┤` rule, the body rows with no rules between them, and a bottom rule, in the quote marker's gray.
  Columns take their widest cell; when the table is wider than the pane, a cap is lowered on the widest columns until it fits, and cells wrap inside their columns, honoring each column's alignment.
  Below four columns of text per column, the table becomes stacked `header: value` lines, one block per body row with a blank line between blocks, and `Column N` for a blank header.
  Links inside cells stay clickable, and text without a `|` renders as before at every width, so only tables are rebuilt on a resize.
- **Link hover (item 26).** crossterm's `EnableMouseCapture` already turns on any-event tracking (`CSI ? 1003 h`, `crossterm/src/event.rs` `EnableMouseCapture::write_ansi`), so `MouseEventKind::Moved` already arrives and only needs handling.
  The link under the pointer, every row of it, draws bold and underlined in the brand accent while mouse capture is on, nothing covers the transcript, and no button is held.
- **Subagent tools (item 37).** The verbs follow the web UI's three phases (`SubagentTool.tsx`, `SUBAGENT_VERBS`): "Spawning", "Spawned", "Failed to spawn", and the same for "Waiting for", "Messaging", and "Interrupting".
  The title is the call's result `title`, else its args `title`, else the title another call in the transcript gave the same `chat_id`, else the chat list's title, else the first eight characters of the chat ID, quoted as `'<title>'`; with no title and no chat ID, the label says "a subagent".
  Expanding the call adds a dim line with the tool name and its raw arguments above the result.
- **Welcome (items 36, 43).** When `welcome.art_file` is unset or unreadable, the art is the bundled Coder wordmark, drawn in the brand accent, with the credit "Unofficial. Not supported by Coder Technologies, Inc." in dim under it.
  The name `scuttle` now shows under any art too, so the screen always names the app, and art wider than the pane is skipped in favor of the name, since it would wrap into noise.
  A blank `art` (as every existing test builds) renders exactly as before, so the welcome snapshots do not change.
- **`/settings` (item 40).** A missing file is created with every key at its default, commented out.
  After the editor exits, the keys that apply live are `mouse`, `busy_behavior`, `composer_max_lines`, `density`, `spinner`, and `chats.pin_icon`; a change to `welcome.show`, `welcome.art_file`, `organization`, or `efforts` is named in the notice as applying on restart.
  A parse error names its line (from the toml error's span) and keeps the settings in effect; an editor that exits with an error reloads nothing.
- **Unavailable model (item 45).** A chat's model is unavailable when the model list has loaded and the model the next message names is missing from the enabled models (deleted or disabled), or its provider is listed as unavailable.
  The footer then reads `/model: <name> (unavailable)` in the warning color, or `/model: unavailable` for a deleted model the list no longer names, and one error notice per chat and model says to pick another.
  Sending on it holds the draft in the core and opens the `/model` table without a request; a send the server refuses for its model (HTTP 400 whose message starts `Invalid model_config_id` or `Invalid model config ID`, since the response has no code or validation to match) does the same and puts its uploaded files back as chips.
  A pick sends the held draft with the new model through the existing send path, and Esc or Ctrl+C gives it back to the composer.
  Unlike the web UI, scuttle never switches the model by itself, since the user asked to choose.
- **Copying the draft (item 46).** Ctrl+O copies the composer's whole text through `Tui::copy`, so the confirmation is the one in the composer's rule; no other binding, the text area's emacs keys included, uses it.
  There is no `/copy draft`, because typing a command replaces the draft it would copy.
- **Task split.** The footer and its accent are one task, because the accent exists for the footer; the composer rule and the slash menu are one task, because both change the composer's rows in `draw_at`; the copy row follows them, since it shares that layout.
  `/chats` is two tasks: the row content (pin and summary) can be rejected apart from the search row and its operators, which also own the `/help` text that documents them.
  `/settings` comes last, because it applies the keys earlier tasks add.

/// How many colors the terminal shows, which decides how the brand accent is drawn.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Colors {
    /// 24-bit color.
    TrueColor,
    /// The 256 indexed colors.
    Ansi256,
    /// `NO_COLOR` is set, so the brand accent is plain text.
    None,
}

impl Colors {
    /// Reads the environment through `env`: `NO_COLOR` set to anything but an empty string
    /// turns color off, as no-color.org asks, and a `COLORTERM` of `truecolor` or `24bit` says
    /// the terminal takes 24-bit color.
    pub fn detect(env: impl Fn(&str) -> Option<String>) -> Colors {
        if env("NO_COLOR").is_some_and(|v| !v.is_empty()) {
            return Colors::None;
        }
        match env("COLORTERM").as_deref() {
            Some("truecolor" | "24bit") => Colors::TrueColor,
            _ => Colors::Ansi256,
        }
    }

/// One footer field: the slash command that changes it, if any, and its value.
struct Field {
    command: Option<&'static str>,
    value: String,
}

impl Field {
    fn command(command: &'static str, value: String) -> Field {
        Field {
            command: Some(command),
            value,
        }
    }

    fn plain(value: String) -> Field {
        Field {
            command: None,
            value,
        }
    }

    /// The field as it reads, such as `/effort: high`.
    fn text(&self) -> String {
        match self.command {
            Some(command) => format!("{command}: {}", self.value),
            None => self.value.clone(),
        }
    }
}

/// The columns `fields` take, joined with ` · `.
fn fields_width(fields: &[Field]) -> usize {
    let joined: Vec<String> = fields.iter().map(Field::text).collect();
    cells_width(&joined.join(" · "))
}

/// `fields` as spans cut to `width` columns: each command in the brand accent, and its value,
/// the separators, and the plain fields dim.
fn field_spans(fields: &[Field], theme: &Theme, width: usize) -> Vec<Span<'static>> {
    let mut spans = Vec::new();
    for (i, field) in fields.iter().enumerate() {
        if i > 0 {
            spans.push(Span::styled(" · ", theme.dim));
        }
        match field.command {
            Some(command) => {
                spans.push(Span::styled(command, theme.brand));
                spans.push(Span::styled(format!(": {}", field.value), theme.dim));
            }
            None => spans.push(Span::styled(field.value.clone(), theme.dim)),
        }
    }
    let mut left = width;
    let mut out = Vec::new();
    for span in spans {
        let text = fit(span.content.to_string(), left);
        // `fit` turns line breaks into spaces, which keeps the byte length.
        let cut = text.len() < span.content.len();
        left -= cells_width(&text);
        if !text.is_empty() {
            out.push(Span::styled(text, span.style));
        }
        if cut {
            break;
        }
    }
    out
}

    pub fn height(&self, width: u16) -> u16 {
        let lines = self.area.lines();
        let gutter = if lines.len() > 1 {
            lines.len().to_string().len() + 2
        } else {
            0

        let text_width = usize::from(width).saturating_sub(gutter).max(1);
        let rows: usize = lines.iter().map(|l| wrapped_rows(l, text_width)).sum();
        rows.clamp(1, usize::from(self.max_lines)) as u16 + 1

/// Whether `enter` saved the window title on the title stack, so `finish` pops it only once.
static TITLE_PUSHED: AtomicBool = AtomicBool::new(false);

/// Saves the window title on the terminal's title stack (XTWINOPS `CSI 22 ; 0 t`), so
/// `finish` can put it back. A terminal without a title stack ignores it.
pub const PUSH_TITLE: &str = "\x1b[22;0t";

/// Restores the window title `PUSH_TITLE` saved (XTWINOPS `CSI 23 ; 0 t`).
pub const POP_TITLE: &str = "\x1b[23;0t";

/// Writes `text` to the terminal as it is.
fn write_raw(text: &str) -> std::io::Result<()> {
    let mut out = stdout();
    out.write_all(text.as_bytes())?;
    out.flush()
}

/// The OSC 2 sequence that sets the window title to `title`. Control characters are dropped,
/// so a title can neither end the sequence early nor start another one.
pub fn title_sequence(title: &str) -> String {
    let clean: String = title.chars().filter(|c| !c.is_control()).collect();
    format!("\x1b]2;{clean}\x07")
}

/// Sets the window title.
pub fn set_title(title: &str) -> std::io::Result<()> {
    write_raw(&title_sequence(title))
}

/// Leaves the terminal for good: everything `leave` restores, then the window title `enter`
/// saved. Safe to call more than once.
pub fn finish() -> std::io::Result<()> {
    let left = leave();
    if TITLE_PUSHED.swap(false, Ordering::SeqCst) {
        let _ = write_raw(POP_TITLE);
    }
    left
}

/// How often the spinner advances, and so how often the screen redraws while the agent works.
pub const SPINNER_INTERVAL: Duration = Duration::from_millis(100);

const BRAILLE: [&str; 10] = ["⠋", "⠙", "⠹", "⠸", "⠼", "⠴", "⠦", "⠧", "⠇", "⠏"];
const LINE: [&str; 4] = ["-", "\\", "|", "/"];
const ARC: [&str; 6] = ["◜", "◠", "◝", "◞", "◡", "◟"];
const BOUNCE: [&str; 8] = ["⠁", "⠂", "⠄", "⡀", "⢀", "⠠", "⠐", "⠈"];
const BAR: [&str; 14] = [

/// A spinner's look: the frames it cycles through. Every frame is one cell wide, because the
/// transcript's and the tables' spinners are painted into a single cell.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum SpinnerStyle {
    Braille,
    Line,
    Arc,
    Bounce,
    Bar,
}

impl SpinnerStyle {
    /// Every style, in the order a random pick indexes them.
    pub const ALL: [SpinnerStyle; 5] = [
        SpinnerStyle::Braille,
        SpinnerStyle::Line,
        SpinnerStyle::Arc,
        SpinnerStyle::Bounce,
        SpinnerStyle::Bar,
    ];

    fn frames(self) -> &'static [&'static str] {
        match self {
            SpinnerStyle::Braille => &BRAILLE,
            SpinnerStyle::Line => &LINE,
            SpinnerStyle::Arc => &ARC,
            SpinnerStyle::Bounce => &BOUNCE,
            SpinnerStyle::Bar => &BAR,
        }
    }

    /// The frame for `elapsed` time since the app started.
    pub fn frame(self, elapsed: Duration) -> &'static str {
        let frames = self.frames();
        let step = elapsed.as_millis() / SPINNER_INTERVAL.as_millis();
        frames[(step % frames.len() as u128) as usize]
    }

    /// The style `setting` names, or for `Random` the one `seed` picks.
    pub fn pick(setting: SpinnerSetting, seed: u64) -> SpinnerStyle {
        match setting {
            SpinnerSetting::Random => Self::ALL[(seed % Self::ALL.len() as u64) as usize],
            SpinnerSetting::Braille => SpinnerStyle::Braille,
            SpinnerSetting::Line => SpinnerStyle::Line,
            SpinnerSetting::Arc => SpinnerStyle::Arc,
            SpinnerSetting::Bounce => SpinnerStyle::Bounce,
            SpinnerSetting::Bar => SpinnerStyle::Bar,
        }
    }
}

/// the turn's style over them.

    SpinnerStyle::Braille.frame(elapsed)

/// `text` split at whitespace outside double quotes, the way the server splits `q`.
fn terms(text: &str) -> Vec<&str> {
    let mut out = Vec::new();
    let mut start = None;
    let mut quoted = false;
    for (i, c) in text.char_indices() {
        if c == '"' {
            quoted = !quoted;
        }
        if c.is_whitespace() && !quoted {
            if let Some(s) = start.take() {
                out.push(&text[s..i]);
            }
        } else if start.is_none() {
            start = Some(i);
        }
    }
    if let Some(s) = start {
        out.push(&text[s..]);
    }
    out
}

/// Whether `term` is `key:value` with a value and a key the server accepts, in any case.
fn is_operator(term: &str) -> bool {
    term.split_once(':').is_some_and(|(key, value)| {
        !value.is_empty() && SEARCH_KEYS.contains(&key.to_ascii_lowercase().as_str())

/// one `search:"…"` term, since the server refuses a bare word. Text with no operator is all
/// one search. A quote inside the searched words would end the value early, so it becomes a
/// space.
fn search_q(text: &str) -> String {
    let (operators, words): (Vec<&str>, Vec<&str>) =
        terms(text).into_iter().partition(|t| is_operator(t));
    if operators.is_empty() {
        return format!("search:\"{}\"", text.replace('"', " "));
    }
    let mut out: Vec<String> = operators.into_iter().map(str::to_owned).collect();
    if !words.is_empty() {
        out.push(format!(
            "search:\"{}\"",
            words.join(" ").replace('"', " ")
        ));
    }
    out.join(" ")
}

/// The parts of display columns `cols` of an unwrapped line that fall on each of `rows`, the
/// rows `wrap_line` made of that line, as (row index, columns within that row).
pub fn cols_on_rows(rows: &[Line<'static>], cols: &Range<usize>) -> Vec<(usize, Range<usize>)> {
    let mut parts = Vec::new();
    let mut at = 0;
    for (i, row) in rows.iter().enumerate() {
        let width: usize = row.spans.iter().map(|s| cells_width(&s.content)).sum();
        let (from, to) = (cols.start.max(at), cols.end.min(at + width));
        if from < to {
            parts.push((i, from - at..to - at));
        }
        at += width;
    }
    parts
}

use std::hash::{Hash, Hasher};
use std::ops::Range;

use pulldown_cmark::{Alignment, CodeBlockKind, Event, HeadingLevel, Options, Parser, Tag, TagEnd};

/// Cap on cached entries; the cache is cleared rather than evicted individually since
/// rendering is cheap and a transcript's distinct messages rarely exceed this.
const CACHE_LIMIT: usize = 512;

/// The narrowest a table column shrinks to; below that the table stacks its rows instead.
const MIN_COLUMN: usize = 4;

thread_local! {
    static CACHE: RefCell<HashMap<u64, (String, u16, Rendered)>> = RefCell::new(HashMap::new());
}

/// The width that decides how `text` renders: the pane's for text that may hold a table, which
/// is laid out to fit it, and 0 for any other text, which renders the same at every width, so
/// a resize finds it cached.
fn layout_width(text: &str, width: u16) -> u16 {
    if text.contains('|') { width } else { 0 }
}

fn cache_key(text: &str, width: u16) -> u64 {
    let mut hasher = DefaultHasher::new();
    text.hash(&mut hasher);
    width.hash(&mut hasher);
    highlight::is_ready().hash(&mut hasher);
    hasher.finish()
}

/// `render`, memoized by the text, the width a table in it is laid out for, and whether syntax
/// highlighting is ready, so re-rendering an unchanged message (every redraw, until the
/// assets warm up flips highlighting on) doesn't redo the parse and highlight work. The text
/// and width are stored alongside the hash so a collision is detected as a miss rather than
/// returning the wrong `Rendered`.
pub fn render_cached(text: &str, width: u16) -> Rendered {
    let width = layout_width(text, width);
    let key = cache_key(text, width);
    CACHE.with(|cache| {
        if let Some((cached_text, cached_width, hit)) = cache.borrow().get(&key)
            && cached_text == text
            && *cached_width == width
        {
            return hit.clone();
        }
        let rendered = render(text, width);
        let mut cache = cache.borrow_mut();
        if cache.len() >= CACHE_LIMIT {
            cache.clear();
        }
        cache.insert(key, (text.to_owned(), width, rendered.clone()));
        rendered
    })
}

/// One table cell: its styled text, and its links as span index ranges into it.
#[derive(Default)]
struct Cell {
    spans: Vec<Span<'static>>,
    links: Vec<(usize, usize, String)>,
}

/// A table being read: its column alignments, its header row, and its body rows.
struct TableBuf {
    alignments: Vec<Alignment>,
    header: Vec<Cell>,
    rows: Vec<Vec<Cell>>,
    /// The cells of the row being read.
    row: Vec<Cell>,
}

impl TableBuf {
    /// How many columns the table has: its alignment row's count, or more if a row runs longer.
    fn columns(&self) -> usize {
        std::iter::once(&self.header)
            .chain(&self.rows)
            .map(Vec::len)
            .max()
            .unwrap_or(0)
            .max(self.alignments.len())
    }
}

/// One rendered table line, and its links as display columns of the line.
#[derive(Default)]
struct TableLine {
    spans: Vec<Span<'static>>,
    links: Vec<(Range<usize>, String)>,
}

/// The display columns `spans` take.
fn span_cols(spans: &[Span]) -> usize {
    spans.iter().map(|s| cells_width(&s.content)).sum()
}

/// `cell` wrapped to `width` columns, with each link's part on each row as (row, columns, URL).
fn wrap_cell(cell: &Cell, width: usize) -> (Vec<Line<'static>>, Vec<(usize, Range<usize>, String)>) {
    let rows = wrap_line(&Line::from(cell.spans.clone()), width.max(1) as u16);
    let mut links = Vec::new();
    for (start, end, url) in &cell.links {
        let from = span_cols(&cell.spans[..*start]);
        let to = from + span_cols(&cell.spans[*start..*end]);
        for (row, cols) in cols_on_rows(&rows, &(from..to)) {
            links.push((row, cols, url.clone()));
        }
    }
    (rows, links)
}

/// Each column's width when the table, borders included, fits `avail` columns: its widest
/// cell, or when that is too wide, a cap lowered on the widest columns until it fits, with the
/// columns left over handed back to the capped ones. `None` when even `MIN_COLUMN` columns of
/// text per column do not fit.
fn column_widths(table: &TableBuf, avail: usize) -> Option<Vec<usize>> {
    let count = table.columns();
    if count == 0 {
        return None;
    }
    let mut widths = vec![1; count];
    for row in std::iter::once(&table.header).chain(&table.rows) {
        for (i, cell) in row.iter().enumerate().take(count) {
            widths[i] = widths[i].max(span_cols(&cell.spans));
        }
    }
    // `│ ` before each cell, a space after it, and the closing `│`.
    let budget = avail.checked_sub(3 * count + 1)?;
    if widths.iter().sum::<usize>() <= budget {
        return Some(widths);
    }
    if budget < MIN_COLUMN * count {
        return None;
    }
    let mut cap = widths.iter().copied().max().unwrap_or(1);
    while widths.iter().map(|w| (*w).min(cap)).sum::<usize>() > budget {
        cap -= 1;
    }
    let mut fitted: Vec<usize> = widths.iter().map(|w| (*w).min(cap)).collect();
    let mut spare = budget - fitted.iter().sum::<usize>();
    for (fit, natural) in fitted.iter_mut().zip(&widths) {
        if spare == 0 {
            break;
        }
        if *natural > *fit {
            *fit += 1;
            spare -= 1;
        }
    }
    Some(fitted)
}

/// One table row as lines: every cell wrapped to its column and padded per its alignment, and
/// the row as tall as its tallest cell.
fn grid_row(cells: &[Cell], widths: &[usize], alignments: &[Alignment]) -> Vec<TableLine> {
    let border = Style::new().fg(Color::DarkGray);
    let empty = Cell::default();
    let wrapped: Vec<_> = widths
        .iter()
        .enumerate()
        .map(|(i, width)| wrap_cell(cells.get(i).unwrap_or(&empty), *width))
        .collect();
    let height = wrapped.iter().map(|(rows, _)| rows.len()).max().unwrap_or(1);
    (0..height)
        .map(|r| {
            let mut out = TableLine::default();
            let mut at = 0;
            for (i, (rows, links)) in wrapped.iter().enumerate() {
                out.spans.push(Span::styled("│ ", border));
                at += 2;
                let line = rows.get(r).cloned().unwrap_or_default();
                let pad = widths[i].saturating_sub(span_cols(&line.spans));
                let (before, after) = match alignments.get(i) {
                    Some(Alignment::Right) => (pad, 0),
                    Some(Alignment::Center) => (pad / 2, pad - pad / 2),
                    _ => (0, pad),
                };
                if before > 0 {
                    out.spans.push(Span::raw(" ".repeat(before)));
                }
                let start = at + before;
                out.links.extend(
                    links
                        .iter()
                        .filter(|(row, _, _)| *row == r)
                        .map(|(_, cols, url)| (start + cols.start..start + cols.end, url.clone())),
                );
                out.spans.extend(line.spans);
                out.spans.push(Span::raw(" ".repeat(after + 1)));
                at += widths[i] + 1;
            }
            out.spans.push(Span::styled("│", border));
            out
        })
        .collect()
}

/// The table in box-drawing borders, its columns `widths` wide: a rule above, the header, a
/// rule under it, the body rows, and a rule below.
fn grid(table: &TableBuf, widths: &[usize]) -> Vec<TableLine> {
    let border = Style::new().fg(Color::DarkGray);
    let rule = |left: &str, mid: &str, right: &str| {
        let runs: Vec<String> = widths.iter().map(|w| "─".repeat(w + 2)).collect();
        TableLine {
            spans: vec![Span::styled(format!("{left}{}{right}", runs.join(mid)), border)],
            links: Vec::new(),
        }
    };
    let mut out = vec![rule("┌", "┬", "┐")];
    out.extend(grid_row(&table.header, widths, &table.alignments));
    out.push(rule("├", "┼", "┤"));
    for row in &table.rows {
        out.extend(grid_row(row, widths, &table.alignments));
    }
    out.push(rule("└", "┴", "┘"));
    out
}

/// The table as one block per body row, each cell on its own line as `header: value`, for a
/// pane too narrow for its columns. Blocks are separated by a blank line, and a blank header
/// reads `Column N`.
fn stacked(table: &TableBuf, avail: usize) -> Vec<TableLine> {
    let width = avail.max(2);
    let mut out = Vec::new();
    if table.rows.is_empty() {
        for header in &table.header {
            let (rows, _) = wrap_cell(header, width);
            out.extend(rows.into_iter().map(|row| TableLine {
                spans: row.spans,
                links: Vec::new(),
            }));
        }
        return out;
    }
    for (n, row) in table.rows.iter().enumerate() {
        if n > 0 {
            out.push(TableLine::default());
        }
        for (i, cell) in row.iter().enumerate() {
            let mut spans = match table.header.get(i) {
                Some(h) if span_cols(&h.spans) > 0 => h.spans.clone(),
                _ => vec![Span::styled(
                    format!("Column {}", i + 1),
                    Style::new().add_modifier(Modifier::BOLD),
                )],
            };
            spans.push(Span::raw(": "));
            let offset = spans.len();
            spans.extend(cell.spans.iter().cloned());
            let labeled = Cell {
                spans,
                links: cell
                    .links
                    .iter()
                    .map(|(start, end, url)| (start + offset, end + offset, url.clone()))
                    .collect(),
            };
            let (rows, links) = wrap_cell(&labeled, width);
            for (r, row) in rows.into_iter().enumerate() {
                out.push(TableLine {
                    spans: row.spans,
                    links: links
                        .iter()
                        .filter(|(lr, _, _)| *lr == r)
                        .map(|(_, cols, url)| (cols.clone(), url.clone()))
                        .collect(),
                });
            }
        }
    }
    out
}

/// What a subagent tool does.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Action {
    Spawn,
    Wait,
    Message,
    Interrupt,
}

/// The subagent action tool `name` performs, or `None` for any other tool. `spawn_subagent`
/// and `close_agent` are legacy names that older chats still hold.
pub fn action(name: &str) -> Option<Action> {
    Some(match name {
        "spawn_agent" | "spawn_explore_agent" | "spawn_computer_use_agent" | "spawn_subagent" => {
            Action::Spawn
        }
        "wait_agent" => Action::Wait,
        "message_agent" => Action::Message,
        "interrupt_agent" | "close_agent" => Action::Interrupt,
        _ => return None,
    })

/// How far a call got, which picks its verb.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Phase {
    Running,
    Done,
    Failed,
}

impl Action {
    fn verb(self, phase: Phase) -> &'static str {
        match (self, phase) {
            (Action::Spawn, Phase::Running) => "Spawning",
            (Action::Spawn, Phase::Done) => "Spawned",
            (Action::Spawn, Phase::Failed) => "Failed to spawn",
            (Action::Wait, Phase::Running) => "Waiting for",
            (Action::Wait, Phase::Done) => "Waited for",
            (Action::Wait, Phase::Failed) => "Failed waiting for",
            (Action::Message, Phase::Running) => "Messaging",
            (Action::Message, Phase::Done) => "Messaged",
            (Action::Message, Phase::Failed) => "Failed to message",
            (Action::Interrupt, Phase::Running) => "Interrupting",
            (Action::Interrupt, Phase::Done) => "Interrupted",
            (Action::Interrupt, Phase::Failed) => "Failed to interrupt",
        }
    }

/// `value` as an object, parsing a string that holds one, as the web UI's `parseArgs` does.
fn record(value: Option<&Value>) -> Option<Map<String, Value>> {
    match value? {
        Value::Object(map) => Some(map.clone()),
        Value::String(s) => serde_json::from_str::<Value>(s).ok()?.as_object().cloned(),
        _ => None,
    }
}

/// The trimmed, non-empty string `key` of `map`.
fn text(map: Option<&Map<String, Value>>, key: &str) -> Option<String> {
    map?.get(key)?
        .as_str()
        .map(str::trim)
        .filter(|s| !s.is_empty())
        .map(str::to_owned)
}

/// The title a call's result or arguments give, the result's first.
pub fn provided_title(args: Option<&Value>, result: Option<&Value>) -> Option<String> {
    let (args, result) = (record(args), record(result));
    text(result.as_ref(), "title").or_else(|| text(args.as_ref(), "title"))
}

/// The subagent a call's result or arguments name, the result's first.
pub fn chat_id(args: Option<&Value>, result: Option<&Value>) -> Option<Uuid> {
    let (args, result) = (record(args), record(result));
    text(result.as_ref(), "chat_id")
        .or_else(|| text(args.as_ref(), "chat_id"))
        .and_then(|id| Uuid::parse_str(&id).ok())
}

/// Subagent titles named anywhere in a transcript, by chat ID, so a `wait_agent` that names
/// only the chat finds the title its `spawn_agent` gave.
#[derive(Debug, Default)]
pub struct Titles {
    by_chat: HashMap<Uuid, String>,
}

impl Titles {
    /// Pairs every subagent call in `messages` and `live` with its result by call ID, and
    /// keeps each chat ID that a call and its result name together with a title.
    pub fn collect(messages: &[&types::CodersdkChatMessage], live: &[LiveBlock]) -> Titles {
        let mut call_args: BTreeMap<&str, &Value> = BTreeMap::new();
        let mut call_results: BTreeMap<&str, &Value> = BTreeMap::new();
        for part in messages.iter().flat_map(|m| m.content.iter()) {
            let Some(id) = part.tool_call_id.as_deref() else {
                continue;
            };
            if part.tool_name.as_deref().and_then(action).is_none() {
                continue;
            }
            match part.type_.as_ref().map(|t| t.as_str()) {
                Some("tool-call") => {
                    if let Some(args) = part.args.as_ref() {
                        call_args.insert(id, args);
                    }
                }
                Some("tool-result") => {
                    if let Some(result) = part.result.as_ref() {
                        call_results.insert(id, result);
                    }
                }
                _ => {}
            }
        }
        for block in live {
            match block {
                LiveBlock::ToolCall {
                    id,
                    name,
                    args: Some(args),
                    ..
                } if action(name).is_some() => {
                    call_args.insert(id, args);
                }
                LiveBlock::ToolResult {
                    id,
                    name,
                    result: Some(result),
                    ..
                } if action(name).is_some() => {
                    call_results.insert(id, result);
                }
                _ => {}
            }
        }
        let mut by_chat = HashMap::new();
        for id in call_args.keys().chain(call_results.keys()) {
            let (args, result) = (call_args.get(id).copied(), call_results.get(id).copied());
            if let (Some(chat), Some(title)) = (chat_id(args, result), provided_title(args, result)) {
                by_chat.insert(chat, title);
            }
        }
        Titles { by_chat }
    }
}

/// The verb and title for subagent tool `name`, or `None` for any other tool. The title is
/// the call's own, else the one another call in the transcript gave the same chat, else the
/// chat list's, else the first eight characters of the chat ID; a `None` title means nothing
/// names the subagent.
pub fn label(
    name: &str,
    args: Option<&Value>,
    result: Option<&Value>,
    phase: Phase,
    titles: &Titles,
    chats: Option<&ChatList>,
) -> Option<(&'static str, Option<String>)> {
    let action = action(name)?;
    let chat = chat_id(args, result);
    let title = provided_title(args, result)
        .or_else(|| chat.and_then(|c| titles.by_chat.get(&c).cloned()))
        .or_else(|| {
            let listed = chats?.find(chat?)?.title.as_deref()?.trim();
            (!listed.is_empty()).then(|| listed.to_owned())
        })
        .or_else(|| chat.map(|c| c.to_string()[..8].to_owned()));
    Some((action.verb(phase), title))
}

/// Writes `TEMPLATE` to `path`, creating its directory, unless the file already exists.
pub fn create_if_missing(path: &Path) -> Result<(), ConfigError> {
    use std::io::Write;
    if let Some(dir) = path.parent() {
        std::fs::create_dir_all(dir).map_err(|e| ConfigError::Io(e.to_string()))?;
    }
    // `create_new` never replaces a file, even one made since the check.
    match std::fs::OpenOptions::new()
        .write(true)
        .create_new(true)
        .open(path)
    {
        Ok(mut file) => file
            .write_all(TEMPLATE.as_bytes())
            .map_err(|e| ConfigError::Io(e.to_string())),
        Err(e) if e.kind() == std::io::ErrorKind::AlreadyExists => Ok(()),
        Err(e) => Err(ConfigError::Io(e.to_string())),
    }
}

/// A parse error of `text`, naming the line it is on when toml says where.
fn parse_error(text: &str, e: &toml::de::Error) -> ConfigError {
    let message = e.message().trim();
    match e.span() {
        Some(span) => {
            let before = text.get(..span.start).unwrap_or(text);
            let line = before.matches('\n').count() + 1;
            ConfigError::Parse(format!("line {line}: {message}"))
        }
        None => ConfigError::Parse(message.to_owned()),
    }
}

/// Runs `$EDITOR`, else `$VISUAL`, else `vi`, on `path` in a terminal handoff, resuming with
/// mouse capture `mouse`. Returns the editor's outcome and the terminal's resume outcome.
fn run_editor(path: &std::path::Path, mouse: bool) -> (std::io::Result<()>, std::io::Result<()>) {
    let editor = std::env::var("EDITOR")
        .or_else(|_| std::env::var("VISUAL"))
        .ok()
        .filter(|e| !e.trim().is_empty())
        .unwrap_or_else(|| "vi".into());
    let (handed, resumed) = handoff_round_trip(
        crate::terminal::leave,
        || {
            // `$1` keeps the path out of the shell parse while still allowing
            // `EDITOR="code -w"`.
            let status = crate::runtime::child_command("sh")
                .arg("-c")
                .arg(format!("{editor} \"$1\""))
                .arg("sh")
                .arg(path)
                .status()?;
            if status.success() {
                Ok(())
            } else {
                Err(std::io::Error::other(format!("editor exited with {status}")))
            }
        },
        || crate::terminal::resume(mouse),
    );
    let edited = match handed {
        Handed::Ran(edited) => edited,
        Handed::NotHandedOver(e) => Err(e),
    };
    (edited, resumed)
}

### Task 13: Name the key that sends a queued message now, on the row above the composer (item 44)

"Send now" works today, but nothing near the composer says so.
The key is the user's own send key, from the Coder `agent_chat_send_shortcut` preference: `Tui::key` calls `is_send_key(key, prefs.send_shortcut, keyboard_enhanced)` on a composer that holds only whitespace, and promotes the first queued message when no attachment waits.
In Enter mode that is a plain Enter, and Super+Enter (Cmd+Enter on macOS) is not a send key, so it adds a line.
In modifier mode both Ctrl+Enter and Super+Enter send, but only with keyboard enhancement: `terminal::resume` pushes kitty's `DISAMBIGUATE_ESCAPE_CODES` when the terminal answers the probe, and only then does Cmd+Enter arrive as Super+Enter, in terminals such as kitty, Ghostty, and WezTerm that pass Cmd through.
Without enhancement, Ctrl+Enter and Cmd+Enter arrive as a plain Enter, which adds a line, and Alt+Enter is the fallback `is_send_key` accepts in modifier mode.
With nothing typed, the question menu takes Enter (with any modifier) first, then Ctrl+Enter implements a ready plan, and only then does the send key mean "Send now"; without enhancement (B6) the plan is offered as `/implement` instead of Ctrl+Enter.

This task adds a dim hint on the hint row (B14) while messages wait, such as "⌘↵ sends the next queued message now".
The label is the key `is_send_key` accepts there, so every label is a key that really sends now:

| Send preference | Keyboard enhancement | macOS | Other systems |
| --- | --- | --- | --- |
| Enter | either | `↵` | `↵` |
| Modifier+Enter | on | `⌘↵` | `Ctrl+↵` |
| Modifier+Enter | off | `⌥↵` | `Alt+↵` |

Modifier mode names Cmd on macOS, since that is the key a Mac user presses and Ctrl+Enter there still works too.
Without enhancement there is a fallback, so the hint names Alt instead of a command; on macOS, Option+Enter arrives as Alt+Enter only when the terminal sends Option as Alt (Meta), the same condition the existing "Alt+Enter to send" placeholder already relies on, and `/queue`'s Enter stays the path that works everywhere.

### Task 14: Warn when a chat's model is no longer available, and keep the draft for a model pick (item 45)

A chat remembers its model: `Msg::ChatLoaded` sets `App::selected_model` to the chat's `last_model_config_id` (unless `/model` already chose one), and every `Effect::SendMessage` names that model as `model_config_id`.
The model list (`Msg::CatalogLoaded`, then `Msg::ModelsLoaded`) keeps only the enabled models, so a model that was deleted or disabled since the chat last used it is simply missing, and `App::current_model` and the footer's `/model` field go blank without saying why.
A model whose provider is off or lacks credentials stays in the list, but `App::model_groups` dims it.
Nothing warns before the send, so the user types a message first.

The server then refuses the send in `postChatMessages` (`coderd/exp_chats.go`): `validateExplicitChatModelConfigAvailable` answers HTTP 400 with `Invalid model_config_id: model config not found or disabled.` for a deleted, disabled, or other-organization model, and with `Invalid model_config_id: provider credentials unavailable for this model.` or `Invalid model_config_id: provider is not enabled for this model.` for a provider that cannot serve it (`validateUserChatModelConfigAvailability`); the daemon's own check answers 400 with `Invalid model config ID.` (`chatd.ErrInvalidModelConfigID`).
The response carries only `message`: no `detail`, no `validations` entry naming the field, and no error code, and many other refusals share HTTP 400 (an archived chat, a bad `busy_behavior`, an MCP server).
So the runtime detects this refusal by status 400 plus a message that starts with `Invalid model_config_id` or `Invalid model config ID`, ignoring case; the server checks the content and the MCP selection before the model, so a 400 in that wording is about the model.
Today `runtime.rs` turns it into a plain `Msg::SendFailed` (`mcp_rejected: false`), and `report_failed_send` puts the text back with `Effect::RestoreComposer`, but the uploaded files are gone ("These files were not sent: … Attach them again."), and `/model` has to be typed in the composer, so the user must clear the draft to change the model and then type it again.

The web UI checks on open instead: `AgentChatPage.tsx` sets `hasUnavailableHistoricalModel` from `isUnavailableHistoricalModelID` (`utils/modelOptions.ts`), which counts a model missing from the usable options (enabled, with an available provider), shows "The model used by this chat is not available. A usable model is selected for new messages.", and `submitChatTurn.ts` sends the picker's fallback model, so it never sends the stale ID.
scuttle warns the same way but never switches the model by itself, since the user asked to choose:

- When the model list has loaded and the model the next message names is missing from the enabled models, or its provider is in the provider list and unavailable, `App::unavailable_model` says so, with the model's name when the list still names it (a disabled model) and none for a deleted one.
- The footer then reads `/model: Old (unavailable)`, or `/model: unavailable`, with the value in the warning color, and one error notice per chat and model says "This chat's model, Old, is not available. Pick another with /model before you send."
  The check runs when a chat loads and when the model list loads, so it works in either order.
- Sending on that model holds the draft in the core (`App::model_held`, the way `waiting_send` holds text for uploads), keeps the chips where they are, and opens the `/model` table instead of making a request.
- A send the server refuses for its model becomes `Msg::ModelUnavailable`, which carries the file IDs the send took; the core puts those files back as uploaded chips under the names `sent_files` kept, holds the text, and opens the same table.
- Picking a model in the table sends the held draft with that model through the existing send path (`hold_for_chips`, `send`, `carry_files`), so it gets a new `seq`, its files are recorded for a later failure, and chips that `@path` mentions hold for a later send stay held.
- Esc or Ctrl+C on the table sends the new `Msg::ModelPickerClosed`, which puts the draft back in the composer; the chips are already there, so `Tui`'s `RestoreComposer` handling restores the draft's mentions as for any refusal.
- A refused `/implement` still says to run it again, a refusal that reaches a chat the user left still restores its text and names its lost files, and a refusal with no model list to pick from fails as any send does.
  A refused send that carried a plan-mode change settles that change as failed, exactly as `Msg::SendFailed` does, so the plan-mode queue and its refetch run as before; the resend carries no plan-mode change.
- Leaving the chat while a draft is held gives it back, with the text that waited on a load or on uploads.

    /// Holds `text` while the user picks a model, because the chat's model is unavailable
    /// (`why` says so), and opens the `/model` table: `Msg::ModelChosen` sends it with the
    /// pick, and `Msg::ModelPickerClosed` gives it back. The chips stay above the composer for
    /// the resend. With no model to pick, the text goes back at once.
    fn hold_for_model(&mut self, text: String, why: &str) -> Vec<Effect> {
        if self.no_models() {
            let none = self.no_models_message();
            self.error(format!("{why} {none}"));
            return vec![Effect::RestoreComposer(text)];
        }
        self.model_held = Some(text);
        self.error(format!(
            "{why} Pick a model to send your message, or press Esc to keep editing it."
        ));
        vec![Effect::ShowPicker(Picker::Model)]

    /// Puts the files of the send numbered `seq`, which the server refused for its model, back
    /// above the composer as uploaded chips, under the names the send recorded, so the resend
    /// carries them without a second upload. They go ahead of the chips mentions hold for a
    /// later send, in the order they were attached.
    fn restore_chips(&mut self, seq: u64, files: Vec<Uuid>) {
        let names = self.sent_files.remove(&seq).unwrap_or_default();
        let mut restored = Vec::with_capacity(files.len());
        for (i, id) in files.into_iter().enumerate() {
            self.next_chip += 1;
            restored.push(Chip {
                local: self.next_chip,
                name: names
                    .get(i)
                    .cloned()
                    .unwrap_or_else(|| "attachment".to_owned()),
                size: None,
                state: ChipState::Ready(id),
            });
        }
        self.chips.splice(0..0, restored);
    }

    /// Sends the text held for a model pick to the open chat with the model now chosen,
    /// carrying the chips that waited with it, through the same path as a typed message.
    fn send_held(&mut self, text: String) -> Vec<Effect> {
        let Some(chat) = self.chat_id else {
            return vec![Effect::RestoreComposer(text)];
        };
        let text = match self.hold_for_chips(text) {
            Ok(text) => text,
            Err(held) => return held,
        };
        let turn = self.turn();
        let mut effects = self.send(chat, text, turn);
        self.carry_files(&mut effects);
        effects
    }

### Task 15: Copy the composer's whole draft with Ctrl+O (item 46)

The user wants to copy what they typed before starting over, and nothing copies the composer today: `/copy` copies the last answer or one of its code blocks, and a drag selects only the transcript.
This task adds Ctrl+O, which copies the composer's whole text, every line of it, through the same `Tui::copy` path as the other copies, so the confirmation is the one from Task 3, "Copied N characters", which the fix wave now draws inside the composer's top rule for `COPY_TTL`, with a clipboard warning or failure in the footer.
The draft stays in the composer, and a composer that holds only whitespace copies nothing and says so.
The key is checked where `Tui::key` takes Ctrl+R, after the help overlay, the one-line editor, the effort slider, and the table overlays, so each of those keeps its own keys, and before the composer, whose text area would ignore it.

Ctrl+O is free everywhere a key can reach:
`Tui::key` takes Ctrl+C, Ctrl+R, Ctrl+Enter, the send key, Tab, Backspace, PageUp, PageDown, and End; `Composer::key_action` takes Enter and its modifiers, Ctrl+J, Ctrl+G, Esc, Tab, Up, and Down; the `/chats` overlay takes Ctrl+A, Ctrl+E, Ctrl+P, and Ctrl+U, and no table filter types a Ctrl key; and ratatui-textarea 0.9.2's `TextArea::input` binds Ctrl+A, B, C, D, E, F, H, J, K, M, N, P, R, U, V, W, X, and Y, and Alt+B, D, F, H, N, P, V, `<`, `>`, `[`, and `]`.
Of the Ctrl letters left (I, L, O, Q, S, T, Z), Ctrl+I and Ctrl+M arrive as Tab and Enter without keyboard enhancement, Ctrl+Q and Ctrl+S are flow control on terminals that keep it, Ctrl+Z suspends and Ctrl+L redraws by convention, and Ctrl+O is a plain control byte (`0x0F`) that crossterm reports as Ctrl+O with or without enhancement, so it needs no fallback.

Add after `copy`:

```rust
    /// Copies everything typed in the composer, every line of it, and confirms it in the
    /// composer's rule as any copy does. The draft stays, so it can still be sent.
    fn copy_draft(&mut self) -> Vec<Effect> {
        let text = self.composer.text();
        if text.trim().is_empty() {
            self.notice(Notice::Info(NOTHING_TO_COPY.into()));
            return vec![];
        }
        self.copy(text);
        vec![]
    }
```
