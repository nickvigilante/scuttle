# M1.5: Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the fifteen M1 daily-use items (new chats created in the wrong organization, guidance when an organization has no models, margins, drag selection, a tinted user message, an always-moving activity spinner, a wrapping composer with a line-number gutter, a rule before the answer, a full `/help` with aliases, and `/effort`, `/plan-mode`, `/organization`, `/new`, `/exit`, and `/web`) without changing what M1 already does well.

**Architecture:** Every change follows M1's split: `scuttle-core` gains state and decisions (organization choice, `App::activity`, the chosen effort, plan mode, `TurnOptions`, command aliases, six commands) with no terminal code, `scuttle-tui` renders them and turns mouse drags into selections, and only `runtime.rs` calls the API or starts a process.
Replies that belong to one chat or one organization arrive wrapped in `Msg::ForChat` or `Msg::ForOrg`, and the core drops them once it has moved on, which closes the gap where a message already queued from an old stream reached new state.
The spinner redraws on a 100 ms timer only while the agent works, and a timer frame reuses the transcript lines from the previous frame instead of rebuilding them.
Selection lives in transcript-line coordinates, so it stays on its text when the view scrolls or streams.

**Tech Stack:** Rust 2024, ratatui 0.30.2, ratatui-textarea 0.9.2, crossterm 0.29, tokio (`process`), toml_edit, unicode-segmentation, unicode-width, coder-sdk at `2cdac1eb4d7c2cccb78e541769d694d545a96d98`, insta, wiremock.
No new dependencies.

**Spec:** `docs/specs/2026-09-28-scuttle-design.md` (sections 3, 4, 5 for local settings, and 6), with scope and decisions from `docs/feedback/2026-09-29-m1-daily-use.md` (the M1.5 table, items 1 to 15, and the Decisions section), both in this worktree.
Where the two disagree, the feedback document wins, because it records later decisions: `/plan-mode on|off` replaces the spec's `/plan`, the question menus stay in M2, and `/new`, which the spec lists under M2, moves up to M1.5 at the user's request (feedback item 13).

## Decisions this plan makes that the spec left open

- **Which organization new chats use.** `GET /users/me/organizations` returns memberships in no stable order, and M1 took the first, so a user in `product` (no chat models) and `coder` (`is_default: true`) sometimes got "No chat model is available in this organization." from `coderd/exp_chats.go`.
  scuttle now picks the organization saved as `organization` in the local config while the user is still a member, else the one with `is_default: true`, else the first.
- **What the web UI does.** The Agents page (`site/src/pages/AgentsPage/components/AgentCreateForm.tsx`) picks the same way: the organization stored in `localStorage` under `agents.selected-organization-id` if still permitted, else `is_default`, else the first.
  It also filters the list to organizations where the user may create a chat (`permittedOrganizations` with an authorization check), and it filters workspaces to the chosen organization.
  scuttle matches the order and the workspace filter; it skips the authorization check, because every membership in practice allows creating chats and a failure shows the server's message.
- **Saving the choice.** Only an explicit `/organization` choice is saved; the automatic pick is not, so a deployment that changes its default organization still takes effect.
- **Lists follow the chat.** Model and workspace lists belong to one organization.
  An opened chat loads them for its own `organization_id`, while new chats still go to the picked organization.
  A chosen model does not carry across organizations, because model IDs are per organization.
- **`/organization` with a chat open.** The choice is saved and used by the next `/new`, and the open chat keeps its organization and its lists, so the user is told it takes effect on `/new`.
  With a blank chat, the lists reload at once.
- **No models.** When the loaded model list for the organization is empty, `/model` and a blank chat's first message show the guidance "No chat models are available in <org>. Try /organization." and the message goes back to the composer, instead of a create that is sure to fail.
- **Late replies.** The runtime wraps every stream message in `Msg::ForChat { chat, msg }` and every model or workspace list in `Msg::ForOrg { org, msg }`.
  The core applies the inner message only while that chat is open or those lists still belong to that organization.
  Messages the core builds directly, as tests do, stay unwrapped and always apply.
- **`/new`.** It resets to the state of a launch with no chat ID: the stream closes, the transcript, live turn, toggles, and composer history position clear, the workspace choice and plan mode reset (the spec: new chats have no workspace until one is chosen), and the composer text, chosen model, and chosen effort stay.
  A running agent keeps running on the server; `/new` never interrupts.
  While a chat is still being created or loaded, `/new` asks the user to wait, since the reply would otherwise reopen that chat.
- **Aliases.** `CommandInfo` gains `aliases`.
  `/exit` runs `/quit` and `/org` runs `/organization`; the slash menu and `/help` show them on the command's line, as in "/quit (/exit)", and completing an alias fills in the command's own name.
- **Composer row count.** ratatui-textarea 0.9.2 computes wrapped rows internally (`screen_map.rs`) and exports no row count, so `Composer::height` mirrors its `WordOrGlyph` algorithm (`wrap.rs`, `wrap_word_chunks`), and a test pins the mirror to the rows the widget actually draws.
- **Continuation gutter.** The widget already draws a blank gutter on wrapped continuation rows (`line_number_placeholder`), so no workaround is needed; scuttle only turns line numbers on and off as the line count crosses one.
- **Full-width tint.** A ratatui `Line` style colors only the cells its text covers, so the transcript view marks user rows, and the TUI paints the tint across the whole transcript width after rendering the text.
- **Tint colors.** The tint is 256-color gray 236 on dark terminals and 254 on light ones, chosen from the same dark or light detection M1 uses.
  Blending the terminal's real background would need truecolor, which not every terminal has.
- **Selection model.** Drag selection copies the rendered text, not the raw Markdown; `/copy` still copies raw Markdown.
  Soft-wrapped rows rejoin without a line break, and trailing spaces are dropped from each line.
- **Click versus drag.** A press and release on the same cell is a click (copy a code block, toggle a block), so clicks now act on release instead of press.
- **Selection while streaming.** While the button is held, the view is pinned to the line that was on top when the press began, so new output cannot scroll text out from under the pointer.
- **Spinner placement.** The activity line takes its own row between the transcript and the composer while the agent works, and disappears when it stops.
  It is drawn outside the transcript lines, which is what lets a timer frame skip rebuilding them.
- **When the spinner shows.** From a submit until the chat reports any status other than `waiting` (or an error), then for as long as the status is `running` or `interrupting`.
  `requires_action` stops it, because the agent is waiting on a tool, not working.
- **Effort default.** scuttle sends `reasoning_effort` only after `/effort` chose one the current model offers, so the server's default applies until then.
  The web UI instead always sends a picked effort, falling back to the model's highest, which could raise cost without the user asking.
- **Plan mode on a new chat.** A blank chat sends `plan_mode: "plan"` with the create request.
  A change made while the chat is being created is applied after creation, on the queued message when there is one (so the two requests cannot race) and with `PATCH /chats/{id}` otherwise.
  While an existing chat is still loading, `/plan-mode` asks the user to wait, because the load would overwrite the choice.
- **Plan mode changed elsewhere.** The chat stream does not carry chat updates, so a plan-mode change made in the web UI shows in scuttle only after the chat reloads; the watch socket in M2 fixes this.
- **`/web` without a browser crate.** scuttle runs `open` on macOS and `xdg-open` elsewhere with every standard stream closed, skips that over SSH (`SSH_CONNECTION` or `SSH_TTY` set), and always shows the URL in a notice.
- **Help layout.** `/help` lists every command from `COMMANDS` with its usage, aliases, and description, then every key from a `KEYS` table in the TUI, and scrolls with Up, Down, PageUp, and PageDown when it does not fit; any other key closes it.
- **Task split.** The organization bug comes first because it is the most visible failure.
  The suggested sixth task (all commands) is six tasks here, because `/effort`, `/plan-mode`, aliases, `/organization`, `/new`, and `/web` with `/help` can each be rejected on its own; the `TurnOptions` change to `Effect` lands with `/effort`, the first task that needs it, and `/help` comes last so it lists every command.

```rust
/// One of the user's organizations.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct OrgRef {
    pub id: Uuid,
    pub name: String,
    pub display_name: String,
    pub is_default: bool,
}

impl OrgRef {
    /// The display name, or the name when there is none.
    pub fn label(&self) -> &str {
        if self.display_name.trim().is_empty() {
            &self.name
        } else {
            &self.display_name
        }
    }
}

/// The organization new chats go to: the saved one while the user is still a member, else
/// the default one, else the first. The server returns memberships in no stable order, so
/// the first alone is not a choice. The web UI's Agents page picks in the same order.
pub fn pick_organization(saved: Option<Uuid>, orgs: &[OrgRef]) -> Option<Uuid> {
    saved
        .filter(|id| orgs.iter().any(|o| o.id == *id))
        .or_else(|| orgs.iter().find(|o| o.is_default).map(|o| o.id))
        .or_else(|| orgs.first().map(|o| o.id))
}
```

```rust
    /// The name of organization `id`, or a generic phrase when it is unknown.

        id.and_then(|id| self.organizations.iter().find(|o| o.id == id))
            .map(|o| o.label().to_owned())
            .unwrap_or_else(|| "this organization".into())

    /// Whether the model list loaded and came back empty.
    fn no_models(&self) -> bool {
        self.models_state == ModelsState::Loaded && self.models.is_empty()
    }

    fn no_models_message(&self) -> String {
        format!(
            "No chat models are available in {}. Try /organization.",
            self.org_label(self.lists_org)
        )
    }

    /// Starts loading the model and workspace lists for `org`, unless they already belong to
    /// it. Model IDs are per organization, so a chosen model does not carry over.
    fn load_lists_for(&mut self, org: Uuid) -> Vec<Effect> {
        if self.lists_org == Some(org) {
            return vec![];
        }
        if self.lists_org.is_some() {
            self.selected_model = None;
        }
        self.lists_org = Some(org);
        self.models.clear();
        self.workspaces.clear();
        self.models_state = ModelsState::Loading;
        vec![Effect::FetchModels(org), Effect::FetchWorkspaces(org)]
    }
```

```rust
/// The display width after `text`, starting at column `width`, with tabs advancing to the next
/// stop. This matches `display_width_to` in ratatui-textarea 0.9.2's `wrap.rs`.
fn width_to(text: &str, mut width: usize) -> usize {
    for c in text.chars() {
        if c == '\t' {
            width += TAB - (width % TAB);
        } else {
            width += c.width().unwrap_or(0);
        }
    }
    width
}

/// Rows a word too wide for one row takes when split at grapheme boundaries, following
/// `split_range_by_grapheme_width` in ratatui-textarea 0.9.2.
fn glyph_rows(text: &str, width: usize) -> usize {
    let mut rows = 0;
    let mut used = 0;
    let mut open = false;
    for g in text.graphemes(true) {
        let mut w = width_to(g, used) - used;
        if open && used + w > width {
            rows += 1;
            used = 0;
            w = width_to(g, 0);
        }
        used += w;
        open = true;
        if used > width {
            rows += 1;
            used = 0;
            open = false;
        }
    }
    rows + usize::from(open)
}

/// Rows `line` takes at `width` columns under `WrapMode::WordOrGlyph`. ratatui-textarea
/// computes this in `wrap_word_chunks` but does not export it, so this mirrors that function;
/// `height_counts_the_rows_the_widget_draws` pins the two together.
fn wrapped_rows(line: &str, width: usize) -> usize {
    let width = width.max(1);
    let chunks: Vec<&str> = line.split_word_bounds().collect();
    let mut rows = 0;
    let mut used = 0;
    let mut open = false;
    let mut i = 0;
    while i < chunks.len() {
        let w = width_to(chunks[i], used) - used;
        if used + w <= width {
            used += w;
            open = true;
            i += 1;
            continue;
        }
        if open {
            rows += 1;
            used = 0;
            open = false;
            continue;
        }
        rows += glyph_rows(chunks[i], width);
        used = 0;
        i += 1;
    }
    (rows + usize::from(open)).max(1)
}
```

```rust
//! The animated line that shows what the agent is doing.

use std::time::Duration;

use ratatui::text::{Line, Span};
use scuttle_core::app::Activity;

use crate::theme::Theme;

/// How often the spinner advances, and so how often the screen redraws while the agent works.
pub const SPINNER_INTERVAL: Duration = Duration::from_millis(100);

const FRAMES: [&str; 10] = ["⠋", "⠙", "⠹", "⠸", "⠼", "⠴", "⠦", "⠧", "⠇", "⠏"];

/// The spinner frame for `elapsed` time since the app started.
pub fn spinner_frame(elapsed: Duration) -> &'static str {
    let step = elapsed.as_millis() / SPINNER_INTERVAL.as_millis();
    FRAMES[(step % FRAMES.len() as u128) as usize]
}

pub fn label(activity: &Activity) -> String {
    match activity {
        Activity::Waiting => "Waiting for the agent…".into(),
        Activity::Thinking => "Thinking…".into(),
        Activity::Tool(name) if name.is_empty() => "Running a tool…".into(),
        Activity::Tool(name) => format!("Running {name}…"),
        Activity::Writing => "Writing…".into(),
        Activity::Interrupting => "Interrupting…".into(),
        Activity::Working => "Working…".into(),
    }
}

pub fn activity_line(activity: &Activity, elapsed: Duration, theme: &Theme) -> Line<'static> {
    Line::from(vec![
        Span::styled(format!("{} ", spinner_frame(elapsed)), theme.accent),
        Span::styled(label(activity), theme.dim),
    ])
}
```

```rust
//! Mouse selection in the transcript. Positions are in transcript-line space, not screen
//! rows, so a selection stays on its text while the view scrolls or streams.

use ratatui::text::Line;
use unicode_segmentation::UnicodeSegmentation;
use unicode_width::UnicodeWidthStr;

use crate::transcript_view::View;

/// A cell of the transcript: a row of `View::lines` and a display column in it.
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
pub struct Pos {
    pub line: usize,
    pub col: u16,
}

/// The cells between where a drag started and where the pointer is now, both included.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Selection {
    pub anchor: Pos,
    pub head: Pos,
}

impl Selection {
    /// The first and last selected cell, in reading order.
    pub fn bounds(&self) -> (Pos, Pos) {
        if self.anchor <= self.head {
            (self.anchor, self.head)
        } else {
            (self.head, self.anchor)
        }
    }

    /// The columns `[start, end)` selected on row `line` of a transcript `width` wide. Rows
    /// between the first and last are selected edge to edge, as terminals do.
    pub fn columns(&self, line: usize, width: u16) -> Option<(u16, u16)> {
        let (start, end) = self.bounds();
        if line < start.line || line > end.line {
            return None;
        }
        let from = if line == start.line { start.col } else { 0 };
        let to = if line == end.line {
            end.col.saturating_add(1)
        } else {
            width
        };
        let to = to.min(width);
        (from < to).then_some((from, to))
    }
}

/// The selected text. Rows that continue a soft-wrapped line join without a line break, and
/// every line loses its trailing spaces.
pub fn selected_text(view: &View, selection: &Selection) -> String {
    let (start, end) = selection.bounds();
    let mut out = String::new();
    let Some(last) = view.lines.len().checked_sub(1).map(|l| l.min(end.line)) else {
        return out;
    };
    if start.line > last {
        return out;
    }
    for line in start.line..=last {
        let continues = view.meta.get(line).is_some_and(|m| m.continuation);
        if line > start.line && !continues {
            trim_end(&mut out);
            out.push('\n');
        }
        let from = if line == start.line { start.col } else { 0 };
        let to = (line == end.line).then_some(end.col);
        out.push_str(&cells(&view.lines[line], from, to));
    }
    trim_end(&mut out);
    out
}

fn trim_end(s: &mut String) {
    let keep = s.trim_end_matches(' ').len();
    s.truncate(keep);
}

/// The graphemes of `line` whose first column lies in `from..=to`, where `None` means the end.
fn cells(line: &Line, from: u16, to: Option<u16>) -> String {
    let mut col: u16 = 0;
    let mut out = String::new();
    for span in &line.spans {
        for g in span.content.graphemes(true) {
            if col >= from && to.is_none_or(|to| col <= to) {
                out.push_str(g);
            }
            col = col.saturating_add(g.width() as u16);
        }
    }
    out
}
```

```rust
    fn inside(&self, column: u16, row: u16) -> bool {
        row >= self.area.y
            && row < self.area.y + self.area.height
            && column >= self.area.x
            && column < self.area.x + self.area.width
    }

    /// The transcript cell under the pointer, clamped into the transcript.
    fn pos_at(&self, column: u16, row: u16) -> Pos {
        let bottom = self.area.y + self.area.height.saturating_sub(1);
        let right = self.area.x + self.area.width.saturating_sub(1);
        let row = row.clamp(self.area.y, bottom);
        Pos {
            line: self.top_line() + (row - self.area.y) as usize,
            col: column.clamp(self.area.x, right) - self.area.x,
        }
    }

    fn click(&mut self, column: u16, row: u16) {
        if !self.inside(column, row) {
            return;
        }
        let line = self.top_line() + (row - self.area.y) as usize;
        let target = self
            .view
            .hits
            .iter()
            .rev()
            .find(|h| h.lines.contains(&line))
            .map(|h| h.target.clone());
        match target {
            Some(HitTarget::CopyCode(code)) => self.copy(code),
            Some(HitTarget::Toggle(id)) => {
                let was_toggled = self.toggles.remove(&id);
                if !was_toggled {
                    self.toggles.insert(id);
                }
            }
            None => {}
        }
    }

    fn mouse(&mut self, m: MouseEvent) {
        match m.kind {
            MouseEventKind::Down(MouseButton::Left) => {
                self.selection = None;
                self.drag = (!self.overlay_showing() && self.inside(m.column, m.row)).then(|| {
                    Drag {
                        anchor: self.pos_at(m.column, m.row),
                        moved: false,
                        top: self.top_line(),
                    }
                });
            }
            MouseEventKind::Drag(MouseButton::Left) => self.drag_to(m.column, m.row),
            MouseEventKind::Up(MouseButton::Left) => {
                let Some(drag) = self.drag.take() else {
                    return;
                };
                if !drag.moved {
                    self.click(m.column, m.row);
                } else if let Some(selection) = self.selection {
                    let text = selected_text(&self.view, &selection);
                    if !text.is_empty() {
                        self.copy(text);
                    }
                }
            }
            MouseEventKind::ScrollUp => {
                self.scroll_up(3);
                self.repin();
            }
            MouseEventKind::ScrollDown => {
                self.scroll_down(3);
                self.repin();
            }
            _ => {}
        }
    }

    /// Extends the selection to the pointer, scrolling a line when it leaves the transcript.
    fn drag_to(&mut self, column: u16, row: u16) {
        let Some(mut drag) = self.drag else {
            return;
        };
        if row < self.area.y {
            self.scroll_up(1);
        } else if row >= self.area.y + self.area.height {
            self.scroll_down(1);
        }
        drag.top = self.top_line();
        let head = self.pos_at(column, row);
        drag.moved |= head != drag.anchor;
        if drag.moved {
            self.selection = Some(Selection {
                anchor: drag.anchor,
                head,
            });
        }
        self.drag = Some(drag);
    }

    /// Moves a held drag's pinned top to wherever the user scrolled.
    fn repin(&mut self) {
        let top = self.top_line();
        if let Some(drag) = self.drag.as_mut() {
            drag.top = top;
        }
    }
```

```rust
/// Sets one top-level key in the file, creating it if needed and preserving comments and
/// formatting.
fn set_value(path: &Path, key: &str, value: toml_edit::Item) -> Result<(), ConfigError> {
    let text = match std::fs::read_to_string(path) {
        Ok(t) => t,
        Err(e) if e.kind() == std::io::ErrorKind::NotFound => String::new(),
        Err(e) => return Err(ConfigError::Io(e.to_string())),
    };
    let mut doc: toml_edit::DocumentMut = text
        .parse()
        .map_err(|e: toml_edit::TomlError| ConfigError::Parse(e.to_string()))?;
    doc[key] = value;
    if let Some(dir) = path.parent() {
        std::fs::create_dir_all(dir).map_err(|e| ConfigError::Io(e.to_string()))?;
    }
    std::fs::write(path, doc.to_string()).map_err(|e| ConfigError::Io(e.to_string()))
}
```

```rust
struct StreamSender {

            return false;
        }
        let _ = self.tx.send(Msg::ForChat {
            chat: self.chat,
            msg: Box::new(msg),

    }
```
```rust
}

/// Whether scuttle runs over SSH, where a browser would open on the wrong machine.
fn over_ssh(is_set: impl Fn(&str) -> bool) -> bool {
    is_set("SSH_CONNECTION") || is_set("SSH_TTY")
}

/// Opens `url` with the system browser. Every standard stream is closed, because the opener's
/// output would land on top of the full-screen UI.
async fn open_in_browser(url: &str) -> Result<(), String> {
    if cfg!(test) {
        return Err("not opened in tests".into());
    }
    if over_ssh(|k| std::env::var_os(k).is_some()) {
        return Err("over SSH, so open it on your own machine".into());
    }
    let program = if cfg!(target_os = "macos") {
        "open"
    } else {
        "xdg-open"
    };
    let status = tokio::process::Command::new(program)
        .arg(url)
        .stdin(std::process::Stdio::null())
        .stdout(std::process::Stdio::null())
        .stderr(std::process::Stdio::null())
        .status()
        .await
        .map_err(|e| format!("could not run {program}: {e}"))?;
    if status.success() {
        Ok(())
    } else {
        Err(format!("{program} exited with {status}"))
    }
}
```
