## Round 2: feedback on M1.5 (2026-09-30)

### Decisions on the M1.5 rulings

- Effort follows the web UI: when a chat opens, scuttle uses the chat's `last_reasoning_effort`, then the model default, then the highest effort, and sends it, so the web UI and scuttle stay in sync.
  This reverses the M1.5 "send only after /effort" ruling.
- The footer shows the chat's effort.
- `/effort` with no argument shows the current effort on a slider that the arrow keys adjust.
- `/organization` with a chat open applies on `/new`, which matches the web UI: its organization choice lives only on the new-chat form (`site/src/pages/AgentsPage/components/AgentCreateForm.tsx`), and an open chat keeps its own organization.
- Organizations where the user cannot create chats stay listed for now; an enhancement greys them out with the reason, or filters them the way the web UI does.
